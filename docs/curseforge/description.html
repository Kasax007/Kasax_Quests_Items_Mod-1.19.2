Details: requirements, commands, teams and quest files

Requirements

  • Minecraft 26.3 with Fabric Loader 0.19.5 or newer, or Minecraft 26.2 with Fabric Loader 0.18.4 or newer. Fabric API. On a server, install it on the server and on every client.

Commands

  • Everyone: /quests open and /quests team info | create | invite | join | leave. Operators: reload, givebook, complete, reset and import ftbquests [preview | run | merge] [folder]. /questbook works the same.
  • Joining a team replaces your progress with the team's. Leaving starts you over with empty progress.

Quest files

  • Commas are optional. IDs are 16-digit hex numbers or any readable name.
  • Text takes & colour codes, translation keys like {mypack.quest.title} and JSON text. Pictures: {image:namespace:path.png width:120 height:60}.
  • Rewards can go to the whole team (team_reward) or be claimed on their own (auto).

FTB Quests import

  • preview (the default) changes nothing and writes config/questsicons/ftbquests-import-report.txt. run replaces the book, merge keeps your own chapters and adds the FTB ones. Both back up your quest files to config/questsicons/backups/ first.
  • The folder is config/ftbquests/quests by default; an instance folder, a config folder or a full path works too.
  • Fluid, energy, game stage and KubeJS tasks become checkmark tasks with a clear title. Currency, game stage and KubeJS rewards are skipped. The report lists every case and every id of a mod that is not installed.
