## Quest Icons 1.0.2 (Minecraft 26.3) - hotfix

### Fixed
- **Clicking in the quest book works again.** Minecraft 26.3 numbers the mouse buttons differently
  (left = 1, right = 3). The quest book still expected the old numbers, so a left click only moved the map: quests did
  not open, check tasks ("I am ready to dream", class choice) could not be ticked and rewards could not be claimed.
  Left click, right click (edit mode menus) and middle click (pan) now use the 26.3 buttons.
