# Quest Icons 1.0.0 for Minecraft 26.3

**The big one: Quest Icons is now a complete quest book.**

- Ported to Minecraft 26.3 (Fabric, Java 25).
- New: a full quest system in the spirit of FTB Quests.
  - Chapters and chapter groups, quest maps with 10 node shapes, dependency lines and pictures.
  - Tasks: items (tags too, detect or submit), checkmark, kill, advancement, dimension, biome, structure, XP, statistic, observation and location.
  - Rewards: items, XP, levels, commands, random picks from reward tables, "choose one", loot tables and advancements.
  - Team progress (`/quests team ...`), per-player or team rewards, "Claim all", toasts, pinned quests on the HUD.
  - Quest files in the FTB Quests style: `config/questsicons/quests` (SNBT, one file per chapter).
  - In-game editor for operators: drag quests, link dependencies, add tasks and rewards from the held item, and edit everything as SNBT.
  - Open the book with **J**, the Quest Book item or the button in your inventory.
- New items: Quest Book, four Loot Crates (common to legendary; they roll the book's reward tables) and 20 new icons.
